How it works

A percentage is only half the answer.

56% sounds fine — unless the window opened an hour ago. Quotlet puts how much you've used next to how much of the window has passed, and works out whether you'll make it to the reset.

5h   ██████████│█░░░░░░░  56%   3h 6m
      Resets today 10:30
      Empty in ~1h 29m — 1h 37m before reset

week █████████│██████░░░  90%   3d 19h
      Resets Sunday 3:00

opus ███░░░░░░│░░░░░░░░  18%   3d 19h
      Resets Sunday 3:00 · ~31% by then
  1. The tick is the clock. It marks how much of the window has gone by. A bar past its tick means you're spending faster than time is passing.
  2. The forecast is plain arithmetic. Your average pace so far in this window, carried forward to the reset. No history to collect, no model to train — it works from the first refresh.
  3. Quiet until it matters. When a limit is on track, you just see where it will land. When it isn't, you get one red line saying when it runs out.

What it does

Everything /usage tells you, without opening a terminal.

01 Menu bar

Always in sight

"5h 41% · Wk 62%" right in the menu bar, or just "41% 62%" if you like it compact.

02 Limits

Claude and Codex, side by side

Every Claude limit and, if you use Codex, its 5-hour and weekly limits, one line each with the reset time and a countdown.

03 Forecast

Warns before the wall

Says where each limit will land at the reset, or how long until it runs out if you keep this pace.

04 Today

Speed and cost

Today's output and input tokens, requests, average and peak tok/s, and what it would cost at API prices.

05 History

A usage history window

Daily output and cost by source, a speed trend, weekly-limit history and every session, with CSV export. Daily totals stay on your Mac after Claude Code clears old logs.

06 Alerts

Notifications, four languages

A heads-up at 80, 90 or 95% and when a limit is back. English, 简体中文, 日本語 and 한국어; an HTTP proxy for regions that need one.

Quotlet Cloud new in 0.5

The menu bar stays small. The details live on the web.

Sign in and open app.quotlet.com for the full picture: limits from every Mac you use, session history, which sessions are running or waiting for you, and token trends — on your phone too.

  1. Optional, off by default. Without signing in, Quotlet never talks to anything but Anthropic. Cloud only starts after you sign in on that Mac.
  2. Numbers, not conversations. It sends limits, token counts and session status. Your prompts and code never leave the Mac; session titles can be turned off too.
  3. Stop whenever you like. Sign out on the Mac, or remove it from the website, and it stops sending anything.

Privacy

Don't take our word for it. Check.

No account, no telemetry, nothing to paste. Each claim below comes with a way to verify it yourself.

01

Uses the login Claude Code already has

It reads Claude Code's token from your Keychain with the system security tool. It never refreshes, changes or saves it, and only sends it to Anthropic.

git grep -n accessToken Sources/

02

One outbound host

api.anthropic.com, to ask for your usage. app.quotlet.com is added only after you sign in to Cloud.

sudo lsof -i -a -c Quotlet

03

Your logs stay put

Sessions and tokens are read, never written, from the logs Claude Code and Codex already keep on your Mac.

ls ~/.claude/projects ~/.codex/sessions

04

Signed and notarized

Every release is signed with a Developer ID and notarized by Apple.

spctl -a -vv /Applications/Quotlet.app

05

Open source

MIT licensed. Every line is on GitHub, and you can build the app yourself in one command.

./build.sh install

Install

Three ways in.

Homebrew

brew tap tluo-github/quotlet https://github.com/tluo-github/quotlet
brew trust tluo-github/quotlet
brew install --cask quotlet

Download

Open the DMG and drag Quotlet into Applications. Signed and notarized, so it opens with a double-click.

Download .dmg

Build it yourself

git clone https://github.com/tluo-github/quotlet
cd quotlet && ./build.sh install

Needs the Xcode command line tools.

  • macOS 14 Sonoma or later, Apple silicon or Intel
  • Claude Code installed and signed in with a Claude Pro or Max plan
  • Can't see the numbers? macOS may have tucked the icon away. Hold ⌘ and drag it where you want it.
