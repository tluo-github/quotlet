Everything you check /usage for, without opening a terminal

Always visible

The menu bar shows "5h 41% · Wk 62%" — the 5-hour window and this week at a glance. A compact "41% 62%" style is available too.

Every limit, every reset

Each limit on your plan — 5-hour, weekly, per-model weekly — with reset time, countdown and a time-progress marker. Green when fine, amber and red as you get close.

Notifications

Get notified when a limit nears 80, 90 or 95%, when it runs out, and when it's available again after the reset.

Claude Code sessions

Recent sessions over 24 hours, 7 or 30 days, with a bar showing which ones used the most. Right-click to copy the claude --resume command.

Token stats

Total tokens, tokens per day and per project, counted from your local Claude Code logs — each reply counted once.

Four languages, proxy support

English, 简体中文, 日本語 and 한국어; light, dark or auto. Adjustable refresh rate and an HTTP proxy for regions that need one.

Screenshots

Local first. Nothing leaves your Mac unless you sign in.

Limits come from the same Anthropic endpoint that /usage uses. Quotlet reads Claude Code's existing login from your keychain with the system security tool — it never refreshes or changes it.

Sessions and tokens are read from Claude Code's logs in ~/.claude/projects on this Mac. The only network request is asking Anthropic for your usage.

Install

Download

Open the DMG and drag Quotlet into Applications. The app is signed and notarized by Apple.

Download for macOS

Homebrew

brew tap tluo-github/quotlet https://github.com/tluo-github/quotlet
brew install --cask quotlet
  • macOS 14 Sonoma or later, Apple silicon or Intel
  • Claude Code installed and signed in with a Claude Pro or Max plan
  • Can't see the numbers? macOS may have hidden the icon. Hold ⌘ and drag it where you want it.
