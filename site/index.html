How it works

Local updates between quota refreshes.

Quotlet watches Claude Code, Codex and Antigravity (Gemini) logs on your Mac. Codex quotas come from local logs, Gemini quotas from Antigravity's local service, and optional Claude API readings refresh every 10 minutes with local estimates in between.

5h   ██████████│█░░░░░░░  ≈56.4%   3h 6m
      Resets today 10:30
      ≈ Estimated from new local tokens

week █████████│██████░░░  ≈90.2%   3d 19h
      Resets Sunday 3:00

Claude API refresh · every 10 minutes by default
  • Local logs & services update fast. New session records update tokens, speed and quotas in about a second. Codex reads local logs; Gemini queries Antigravity's local service on 127.0.0.1 and caches the last reading.
  • Claude estimates fill the gaps. After at least two valid readings in the same window, new local Claude tokens estimate quota usage with a ≈ mark, corrected on the next API refresh. Models, caching and other devices affect accuracy.
  • Alerts cover all three providers. Alerts default to on at 90%, at 100% and after reset across Claude, Codex and Gemini — including Claude estimates. Allow macOS notifications when prompted.

What it does

Throughput, quotas, sessions and stats in one panel.

Menu bar

Always in sight

Pick Claude, Codex or Gemini for the menu bar: "5h 41% · Wk 62%" or compact "41% 62%". Switch sources right from the panel.

Limits

Claude, Codex and Gemini, side by side

View 5-hour, weekly and model-specific limits for all three providers in one place. When one nears its limit, a banner suggests switching to another with headroom.

Throughput

Live tok/s across all local AI

A real-time speed gauge and 1m / 2m / 5m chart combine concurrent output from Claude, Codex and Gemini, alongside today's tokens and API-equivalent cost.

Estimates

Updates between refreshes

After calibration, new local tokens update Claude quota estimates in the panel and menu bar. The ≈ mark stays until the next API reading corrects the value.

History

A usage history window

Use Sessions and Stats in the panel for recent activity. Open History for stacked Claude, Codex and Gemini charts, project trends, models, daily totals and CSV export. Daily totals stay on your Mac after old logs are cleared.

Alerts

Notifications, five languages

90%, 100% and reset alerts default to on for Claude, Codex and Gemini, including Claude estimates. Choose 80%, 90% or 95% for the early alert. Requires macOS notification permission.

Quotlet Cloud Optional sync

The menu bar stays small. The details live on the web.

Sign in on your Mac, then check everything at app.quotlet.com or in the iPhone app: limits from every Mac, which sessions are running or waiting for you, token trends, and remote commands.

  • Web dashboard Quotas for each Mac, live session status, analytics by provider, project and model, 90 days of quota history and in-page alerts. Five languages, light and dark.
  • Remote commands Send a prompt to Claude Code, Codex or Antigravity on your Mac from the browser or your phone. Off by default, enabled per Mac, limited to projects from the last 30 days, and every command is logged.
  • iPhone app · coming soon Overview, sessions, remote commands, analytics and devices in a native app, coming soon to the App Store. An Android version is in the works.
  • Optional, off by default. Local stats, Codex and Gemini work without external servers. Enabling Claude quota lookup connects to Anthropic. Browser sign-in enables optional Cloud sync.
  • Choose what to sync. Sync limits, token counts and session status. Session-title uploads have their own switch. Prompts and code stay on your Mac.
  • Stop whenever you like. Sign out on the Mac, or remove it from the website, and it stops sending anything.

Privacy

Don't take our word for it. Check.

Local logs provide token statistics. Claude quota lookup and Cloud sync are optional connections you control in Settings.

Claude quota lookup is optional

Enable it in Settings to read Claude Code credentials through macOS Keychain and request quotas from Anthropic. Use the dedicated authorization button if the system requires access.

git grep -n accessToken Sources/

Connections you enable

Local mode reads files on your Mac and queries Antigravity only on 127.0.0.1. Claude quota lookup uses api.anthropic.com. Cloud sign-in and sync use app.quotlet.com.

sudo lsof -i -a -c Quotlet

Your logs stay put

Sessions and tokens are read, never written, from the logs Claude Code, Codex and Antigravity already keep on your Mac.

ls ~/.claude/projects ~/.codex/sessions ~/.gemini/antigravity/brain

Install

Install your way.

Ask your AI to install it

Copy the prompt into an AI assistant that can run commands on your Mac.

Homebrew

brew tap tluo-github/quotlet https://github.com/tluo-github/quotlet
brew trust tluo-github/quotlet
brew install --cask quotlet

Download

Choose Apple Silicon or Intel, open the DMG and drag Quotlet into Applications. Signed and notarized, so it opens with a double-click.

Apple Silicon (.dmg) Intel (.dmg)

Build it yourself

git clone https://github.com/tluo-github/quotlet
cd quotlet && ./build.sh install

Needs the Xcode command line tools.

  • macOS 13 Ventura or later, Apple silicon or Intel
  • Local Claude Code, Codex or Antigravity (Gemini) logs. Claude quota lookup also needs a Claude subscription login.
  • Can't see the numbers? macOS may have tucked the icon away. Hold ⌘ and drag it where you want it.
