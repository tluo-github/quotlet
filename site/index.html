How it works

Local updates between quota refreshes.

Quotlet watches Claude Code and Codex session files. Enable Claude quota lookup for server readings every 10 minutes, with calibrated local estimates in between.

5h   ██████████│█░░░░░░░  ≈56.4%   3h 6m
      Resets today 10:30
      ≈ Estimated from new local tokens

week █████████│██████░░░  ≈90.2%   3d 19h
      Resets Sunday 3:00

Claude API refresh · every 10 minutes by default
  1. Session files update the numbers. New usage records trigger an update in about a second. Codex quotas also come from its local logs.
  2. Estimates use observed changes. After at least two valid readings in the same window, new Claude tokens can estimate quota usage. The ≈ mark identifies estimates, and each API response corrects them. Models, caching and other devices affect accuracy.
  3. Alerts cover both providers. Alerts default to on at 90%, at 100% and after reset. Claude estimates can trigger them too. Allow macOS notifications when prompted.

What it does

Quotas, sessions and statistics in one panel.

01 Menu bar

Always in sight

"5h 41% · Wk 62%" right in the menu bar, or just "41% 62%" if you like it compact.

02 Limits

Claude and Codex, side by side

Enable Claude quota lookup for 5-hour, weekly and model-specific limits. Codex quotas come from local logs. A switch suggestion appears when one provider is near its limit and the other has room.

03 Estimates

Updates between refreshes

After calibration, new local tokens update Claude quota estimates in the panel and menu bar. The ≈ mark stays until the next API reading corrects the value.

04 Today

Speed and cost

Today's output and input tokens, requests, average and peak tok/s, and what it would cost at API prices.

05 History

A usage history window

Use Sessions and Stats in the panel for recent activity. Open History for project trends, models, daily totals and CSV export. Daily totals stay on your Mac after old logs are cleared.

06 Alerts

Notifications, four languages

90%, 100% and reset alerts default to on for Claude and Codex, including Claude estimates. Choose 80%, 90% or 95% for the early alert. Requires macOS notification permission.

Quotlet Cloud Optional sync

The menu bar stays small. The details live on the web.

Sign in and open app.quotlet.com for the full picture: limits from every Mac you use, session history, which sessions are running or waiting for you, and token trends — on your phone too.

  1. Optional, off by default. Local stats work offline. Enabling Claude quota lookup connects to Anthropic. Browser sign-in enables optional Cloud sync.
  2. Choose what to sync. Sync limits, token counts and session status. Session-title uploads have their own switch. Prompts and code stay on your Mac.
  3. Stop whenever you like. Sign out on the Mac, or remove it from the website, and it stops sending anything.

Privacy

Don't take our word for it. Check.

Local logs provide token statistics. Claude quota lookup and Cloud sync are optional connections you control in Settings.

01

Claude quota lookup is optional

Enable it in Settings to read Claude Code credentials through macOS Keychain and request quotas from Anthropic. Use the dedicated authorization button if the system requires access.

git grep -n accessToken Sources/

02

Connections you enable

Local mode reads files on your Mac. Claude quota lookup uses api.anthropic.com. Cloud sign-in and sync use app.quotlet.com.

sudo lsof -i -a -c Quotlet

03

Your logs stay put

Sessions and tokens are read, never written, from the logs Claude Code and Codex already keep on your Mac.

ls ~/.claude/projects ~/.codex/sessions

04

Signed and notarized

The official download is Developer ID signed and notarized by Apple.

spctl -a -vv /Applications/Quotlet.app

05

Open source

MIT licensed. Every line is on GitHub, and you can build the app yourself in one command.

./build.sh install

Install

Three ways in.

Homebrew

brew tap tluo-github/quotlet https://github.com/tluo-github/quotlet
brew trust tluo-github/quotlet
brew install --cask quotlet

Download

Open the DMG and drag Quotlet into Applications. Signed and notarized, so it opens with a double-click.

Download .dmg

Build it yourself

git clone https://github.com/tluo-github/quotlet
cd quotlet && ./build.sh install

Needs the Xcode command line tools.

  • macOS 14 Sonoma or later, Apple silicon or Intel
  • Local Claude Code or Codex session logs. Claude quota lookup also needs a Claude subscription login
  • Can't see the numbers? macOS may have tucked the icon away. Hold ⌘ and drag it where you want it.
